# ZORR REFERENCE USAGE POLICY R01

Status: PROVISIONAL PRODUCTION RULE
Lore status: NON-LORE

## Owner correction

The op-art / checker / stripe / spiral reference pack was supplied for **brainstorming**, not as a mandatory motif library.

Therefore:

- checkerboards are NOT a default ZORR motif;
- stripes are NOT a default ZORR motif;
- spirals are NOT a default ZORR motif;
- tunnels, arches, spheres, grids, and black/white fields are NOT required visual signatures;
- do not repeat any of these elements simply because they appeared in the reference pack.

## Correct interpretation

References are used to extract **mechanisms**, not surface motifs.

Examples of mechanisms that may be extracted:

- spatial distortion;
- focal pull;
- compression / expansion of visual rhythm;
- figure-ground inversion;
- controlled loss of contour information;
- temporal duplication;
- local perspective violation;
- selective color-state change;
- material-state change;
- graphic simplification under emotional stress;
- character/environment interaction.

A mechanism may be expressed using entirely different geometry, colors, materials, or shapes from the source reference.

## Core rule

`REFERENCE -> EXTRACT TRANSFORMATION LOGIC -> DISCARD SURFACE MOTIF -> DESIGN A NEW ZORR SOLUTION`

Do not do:

`REFERENCE -> COPY CHECKER/STRIPES/SPIRAL -> PLACE AROUND CHARACTER`

## Adult psychedelic fashion target

The visual identity remains:

`ADULT FASHION CONTROL + PSYCHOLOGICAL GRAPHIC EVENT + SELECTIVE SURREAL VIOLATION`

Psychedelia is defined by a change in visual logic, not by the presence of any specific pattern.

Possible non-pattern psychedelic devices include:

- impossible shadow geometry;
- asymmetric value-state changes on the face;
- selective line deletion;
- facial proportion distortion for one emotional beat;
- temporal eye or mouth echoes;
- negative-image islands;
- material shifts (skin to ink, marble, glass, smoke, print texture);
- perspective breaks localized to one facial plane or body part;
- abrupt special-color states;
- silhouette duplication or partial displacement;
- local whiteout / black-mass collapse;
- mismatched lighting systems on the same face;
- controlled frame/crop violations;
- object/space scale contradictions.

## QC

FAIL if a reference motif appears repeatedly without a scene-specific reason.

PASS only when the selected mechanism serves the emotion, composition, motion, or psychological state and the resulting image does not depend on copying the source motif.
