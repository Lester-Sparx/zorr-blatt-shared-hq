## 0. PURPOSE

This file binds the approved `ZORR ANTI-DOLL TRAINING PROTOCOL R01` and `ZORR ANTI-DOLL DRILL PACK R01` to the mathematical error-correction model in `ZORR_ERROR_CORRECTION_EDITING_MATH_R01`.

The objective is not to invent an aesthetic score. The objective is to make recurring puppet-like output measurable enough to diagnose, route to the correct production layer, and repair with the smallest allowed operator.

Core loop:

```text
ANTI-DOLL DRILL
-> OBSERVE
-> MEASURE
-> LOCALIZE
-> CLASSIFY DEFECT / VARIATION / INFORMATION GAP
-> FIND FIRST BROKEN LAYER
-> SELECT MINIMUM ALLOWED OPERATOR
-> RE-MEASURE TARGET + COLLATERAL
-> PASS_CANDIDATE / CHANGES_REQUIRED / ESCALATE_NEW_KEY / UNKNOWN
```

Core law:

```text
LIFE != DEFORMATION
BEAUTY != PROOF
MORE DETAIL != MORE LIFE
MORE MOTION != MORE ACTING
MORE HATCHING != MORE FORM
```

## 3. FIRST-BROKEN-LAYER ROUTER

Always inspect in this order:

```text
DRAWING
-> SPLIT
-> RIG
-> MOTION
-> GARMENT
-> CAMERA
-> FX
-> COMPOSITE
-> RENDER
```

If the drawing is doll-like, FX does not own the repair.
If the rig is breaking the silhouette, texture does not own the repair.
If acting is uniform scaling, hatching does not own the repair.
If new visual information is required, local deformation does not own the repair.

## 5. DRILL 01 — DOLL DETECTOR MEASUREMENT CONTRACT

Input: existing frames/drawings only.

Measure/report separately:

```text
POSE_PATTERN = OBSERVED / WEAK / REPEATED / UNKNOWN
WEIGHT_READ = OBSERVED / WEAK / UNKNOWN
ASYMMETRY_READ = OBSERVED / WEAK / UNKNOWN
MICRO_ACTING = OBSERVED / WEAK / NONE / UNKNOWN
SECONDARY_RESPONSE = OBSERVED / WEAK / NONE / UNKNOWN
VALUE_MASS = OBSERVED / FRAGMENTED / UNKNOWN
HATCH_FUNCTION = FORM / SHADOW / MATERIAL / EMOTION / NOISE / NONE / UNKNOWN
FIRST_BROKEN_LAYER = <one layer or UNKNOWN>
```

No correction is authorized from `D01` until the first causal layer is named or honestly left `UNKNOWN`.

## 6. DRILL 02 — POSE GRAMMAR MEASUREMENT CONTRACT

Per pose record:

```text
pose_id
silhouette_mask
primary_action_line
head_axis
shoulder_axis
pelvis_axis
support_side
major_negative_spaces[]
hand_intent
face_landmarks_if_available
source_provenance
```

Useful measurements:

- silhouette area and boundary displacement;
- connected negative-space components, area and centroid;
- relative shoulder/pelvis/head orientations as descriptors;
- identity residual after allowed global head/body transform where landmarks exist.

Do NOT invent a threshold such as `shoulder-pelvis difference > N degrees = alive`.

Pattern-loop candidate:

```text
MULTIPLE POSES SHARE THE SAME LARGE-FORM RELATIONSHIPS
AND THE SAME NEGATIVE-SPACE TOPOLOGY
DESPITE DIFFERENT INTENT LABELS.
```

That is a review trigger, not an automatic universal FAIL threshold.

## 7. DRILL 03 — WEIGHT MEASUREMENT CONTRACT

Required observations:

```text
support_side
contact_region
pelvis_shift
shoulder_counterbalance
free_leg_state
centerline_relation
silhouette_asymmetry
```

If ground/contact evidence is available, measure screen-space or authored-stage contact error directly.

If contact geometry is unavailable, do not fabricate a center-of-mass truth from pixels alone. Report `WEIGHT_PHYSICS = NOT_PROVEN` and keep the visual-read test separate.

Repair routing:

- wrong pose/key drawing -> drawing/C7;
- correct drawing but misplaced element -> C2;
- rig deforms support incorrectly -> C6;
- camera creates false apparent imbalance -> camera layer before character repair.

## 8. DRILL 04 — MICRO-LIFE MEASUREMENT CONTRACT

Primary anti-puppet test:

```text
FIT BEST GLOBAL SCALE + TRANSLATION TO BODY MOTION
THEN MEASURE RESIDUAL LOCAL MOTION.
```

If almost all visible change is explained by global scale/translation, classify:

`PUPPET_SCALE_CANDIDATE = YES`

Do not automatically hard-FAIL without calibrated evidence; require visual/shot review.

Track where available:

- torso trajectory;
- head trajectory;
- shoulder trajectory;
- face/eye/jaw local state if actually authored/measurable;
- timing state: HOLD / ANTICIPATION / ACCELERATION / IMPACT / REACTION / SETTLE;
- velocity / acceleration / jerk as descriptors, never as universal beauty thresholds.

Repair:

- timing problem -> C5;
- skeleton/mesh coupling problem -> C6;
- required new acting shape -> C7.

## 9. DRILL 05 — SECONDARY MOTION MEASUREMENT CONTRACT

For primary trajectory `x_p(k)` and secondary trajectory `x_s(k)`, measure cross-correlation lag:

```math
R_{ps}(tau) = sum_k x_p(k) x_s(k+tau)
```

```math
tau* = argmax_tau R_{ps}(tau)
```

Also record:

```text
lag_frames
lag_seconds
overshoot
settling_time
oscillation_frequency
phase_consistency
root_attachment_error
jitter
```

Hard structural failures can include broken attachment or impossible layer relation when exact evidence exists.

The artistic amount of lag remains SOFT until calibrated.

## 10. DRILL 06 — VALUE MASS MEASUREMENT CONTRACT

Before hatching/texture review, inspect large value regions.

Record:

```text
LIGHT region mask / occupancy
MID region mask / occupancy
DARK region mask / occupancy
face/local-background luminance relationship
focal-anchor value separation
major garment value separation
```

Do not declare `K=3` a universal production law. Three masses are a training simplification for the drill; actual production bands remain shot-specific.

Repair:

- local value/chroma/contrast cause -> C1;
- broken geometry masquerading as shading -> route back to geometry/drawing;
- new authored shadow design -> drawing decision, not automatic radiometric correction.

## 12. DRILL 08 — PATTERN BREAKER MEASUREMENT CONTRACT

```text

head_axis_family
torso_curve_family

```

Do not maximize novelty blindly.

```text

```

If variation destroys identity, it is not a successful anti-doll repair.

If identity is preserved but every pose collapses to the same large-form pattern, the anti-doll lesson remains `PARTIAL`.

## 16. NEW KEY / REDRAW ESCALATION LAW

Immediate C7 escalation candidate when:

- head turn reveals an unseen facial plane;
- previously occluded anatomy becomes visible;
- garment reverse side or new construction must appear;
- current drawing cannot represent the desired silhouette without destructive warp;
- Plastic deformation budget is visibly/structurally exceeded;
- repeated C2/C6 repair attacks the symptom while the source state itself is wrong;
- a new emotional/body acting shape is required rather than interpolation of the current one.

Compact rule:

```text
NEW VISUAL INFORMATION REQUIRED
=> NEW KEY / REDRAW
=> NOT EXTREME WARP
```
