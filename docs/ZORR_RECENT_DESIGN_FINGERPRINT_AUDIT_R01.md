## 0. WHY THIS AUDIT EXISTS

Recent owner feedback repeatedly rejected outputs as:
- doll-like;
- repetitive;
- identity-drifting;
- using a glued / decorative hand;
- visually polished but compositionally same.

This audit does not assign one similarity percentage. It uses the independent variation axes defined by #233 and records the repeated pattern family qualitatively.

## 2. AXIS-BY-AXIS REPETITION

### POSE_ARTICULATION

Observed repetition:
- limited visible joint variation;
- arms mostly lowered, chest-adjacent, or one arm extended;
- torso rarely compressed/crouched/seated/twisted strongly;
- no broad articulation family coverage.

Status:

```text
REPETITION = HIGH QUALITATIVELY
```

No numeric threshold claimed.

### POSE_PRESENTATION

Repeated:
- frontal / mild 3/4;
- portrait-oriented centered body;
- torso upright with slight lean;
- similar projected body scale.

Under-covered:
- profile;
- back/over-shoulder;
- high top-down;
- strong low-angle;
- seated triangle;
- crouch;
- off-frame action;
- extreme crop destroying normal body presentation.

### EXPRESSION_GEOMETRY

Repeated:
- brow depression / inward angle;
- narrowed eyes;
- direct gaze;
- compressed mouth;
- limited mouth opening;
- limited lower-lid / cheek / nostril / jaw-state diversity.

Under-covered:
- shock / sclera exposure;
- fatigue;
- amusement without brow aggression;
- disgust;
- grief / withheld reaction;
- speaking / breathing in-between mouth states;
- gaze away from camera;
- one-sided facial action.

### ACTING_INTENT

Repeated:

THREAT

- social interaction with a second actor/object;

### COLOR

### POSTER_LAYOUT

Repeated:

## 3. IDENTITY / CANON DRIFT FAILURE

At least one recent edit improved apparent dynamism but changed:
- face construction;
- hair construction;
- costume family;
- accessories;
- overall person identity.

Therefore:

```text
IDENTITY DRIFT = PROVEN FAILURE MODE IN CURRENT SESSION
```

This overrides aesthetic success.

Do not reward novelty created by changing frozen identity axes.

## 4. GLUED-HAND FAILURE

Current repeated failure pattern:

```text
BIG FOREGROUND HAND
+ STATIC OR WEAK SHOULDER RESPONSE
+ LIMITED TORSO FORCE TRANSFER
+ DECORATIVE FINGER FAN
```

Corrective rule is not 'draw the hand better'.

Use:

```text
ACTION VERB
-> TARGET
-> TORSO
-> SCAPULA / SHOULDER
-> ELBOW
-> WRIST
-> PALM
-> FINGER HIERARCHY
```

Alternative correction:

```text
REMOVE HAND AS PRIMARY ACTION CARRIER
```

and let weapon / head / crop / shadow / garment / object / second actor carry the shot.

## 7. NEXT-CANDIDATE RULE

Before producing a new concept, compare it to P11.

Reject before rendering if it repeats most of:

```text
THREAT/CONTROL
+ WHITE SUIT AS MAIN LIGHT MASS
+ CENTERED CHEST/WAIST-UP
+ HARD STARE
+ HAND NEAR CHEST OR CAMERA
+ DARK LUXURY ARCHITECTURE
+ VERTICAL NEON
```

A next candidate should deliberately change at least several *structural* active axes, for example:

```text
ACTING_INTENT
SILHOUETTE
POSE_PRESENTATION
NEGATIVE_SPACE
CAMERA
ACTION_CARRIER
POSTER_LAYOUT
```

Color/light change alone does not count as design expansion.

## 8. FARTHEST-POINT MANUAL APPLICATION

Until an automated fingerprint tool exists, use manual max-min logic:

1. identify recent dominant pattern P11;
2. list candidate concepts;
3. discard canon-breaking variants;
4. for each candidate mark which structural axes differ from P11 and other recent outputs;
5. choose the candidate with the broadest meaningful structural separation, not the prettiest superficial variation;
6. render only after the design gate passes.
