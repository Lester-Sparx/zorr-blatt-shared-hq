# ZORR BLATT — VISUAL TABOO #1 — NO EXTERNAL AESTHETIC BINDINGS

STATUS = ACTIVE GLOBAL PRODUCTION LAW CANDIDATE
DURABLE ISSUE AUTHORITY = #201
SCOPE = ALL CHARACTER / ENVIRONMENT / TEXTURE / FX / SALVADOR / GENERATION / ART DIRECTION

## HARD LAW

`NO EXTERNAL AESTHETIC BINDINGS`

ZORR BLATT must never be aesthetically defined by an external genre, artist, studio, franchise, existing character, named visual style, or external image-reference identity.

## FORBIDDEN

- prompts/instructions such as `anime style`, `manga style`, or equivalent genre labels used as style authority;
- `like X`, `in the style of Y`, artist/studio/franchise/character comparisons;
- external images as ZORR style targets or aesthetic templates;
- importing another character/image's face/body/costume/silhouette language into ZORR identity;
- internet image search for aesthetic imitation;
- describing ZORR production law by analogy to external IP or visual brands.

## ALLOWED

- internal ZORR visual anchors explicitly approved by OWNER;
- mathematical / measurable ZORR drawing and texture laws;
- character source images only as `SOURCE / IDENTITY EVIDENCE`, never automatic style authority;
- internet/upstream research for code, algorithms, mathematics, rendering methods, documentation, QC methods and open-source implementation;
- generic technical terms describing measurable rendering behavior without binding ZORR to an external aesthetic identity.

## SALVADOR LAW

SALVADOR prompts, conditioning manifests, datasets and training captions must not contain external aesthetic bindings.

SALVADOR learns:

`ZORR INTERNAL STYLE LAW + CHARACTER TRUTH + GEOMETRY/POSE CONSTRAINTS`

not:

`EXTERNAL STYLE LABEL / EXTERNAL IMAGE IMITATION`.

Any external-aesthetic binding in a production task is fail-closed:

`VISUAL_TABOO_1_VIOLATION = FAIL`

## RESEARCH BOUNDARY

External research remains encouraged for acceleration, but only for:

`OPEN CODE -> MATH -> ALGORITHMS -> DOCUMENTATION -> QC`

not for aesthetic imitation.

## SUPERSESSION

This law supersedes prior casual descriptions that compared ZORR to "anime" or any other external visual category. Those labels are non-authoritative and must not be used going forward.
