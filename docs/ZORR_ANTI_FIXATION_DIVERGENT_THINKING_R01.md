# ZORR ANTI-FIXATION / DIVERGENT THINKING R01

## Problem
Recent concept work repeated the same surface solution while changing only the emotion label: chest-up portrait, hard stare, brow compression, hand near lapel/chest, dark background, colored edge/split light, cream suit, hatching, posed peak. This is design fixation.

Design fixation is a measured phenomenon: prior examples and familiar solution classes can narrow the explored design space. Examples can inspire, but familiar/near examples also increase the risk of reproducing the same solution family.

## Research basis
- Jansson & Smith (1991), Design Studies: design fixation is measurable and can constrain conceptual design.
- Crilly & Cardoso (2017), Design Studies: fixation/inspiration should be treated as a design-process problem and addressed through tools and training.
- Chan & Schunn (2015), Cognitive Science: far analogies can increase concept-generation rate and support deeper exploration; effects are not a simple one-step novelty jump.
- Design-by-analogy research: less-common and far-field examples can improve novelty; near examples can improve completion but also increase fixation risk.
- Alternative Uses Task research (2023): a design-independent divergent task can reduce design fixation and improve idea quantity/novelty.
- Divergent-thinking review (2022): flexible attention switching and inhibition matter; creativity is not just producing more ideas but changing search mechanisms.
- Constraint meta-analysis (2022): constraints can support creativity; moderate constraints are often more useful than either no constraint or overconstraint.
- Geneplore model: separate GENERATION from EXPLORATION. Early generation under too-specific target control tends to produce stereotyped solutions.
- Face/body/context meta-analysis (2025): perceived emotion is integrative; body posture and scene context can influence emotion interpretation as strongly as facial information.
- Laban Movement Analysis: movement can be decomposed into Body / Effort / Space / Shape. Useful Effort axes include strong-light, sudden-sustained, direct-indirect, bound-free.

## ZORR correction
Emotion labels must not select a stock visual package. The same 'dangerous man' solution is forbidden as a universal carrier for rage, dominance, jealousy, obsession, silence, etc.

New rule:

EMOTION GOAL -> BEHAVIORAL CONTRADICTION -> BODY ACTION -> HAND FUNCTION -> SPATIAL RELATION -> TEMPORAL STATE -> CAMERA -> VALUE/LIGHT -> COLOR -> RENDER

Style is applied last, not first.

## Generation / exploration separation
### Phase A: GENERATE
Produce at least 12 concept skeletons without rendering. No quality ranking yet.

Each skeleton must specify:
1. framing
2. camera
3. pose
4. hand role
5. facial mechanism
6. body Effort profile
7. spatial operator
8. lighting model
9. palette family
10. render language
11. environment logic
12. temporal state
13. far analogy from a non-anime domain

### Phase B: DE-FIX
Before selecting a concept:
- run a 60-90 second design-independent divergent task or random-domain analogy pass;
- forbid the dominant motifs from the last accepted concepts;
- force at least one non-anime functional analogy: auction, surgery, geology, courtroom behavior, animal territoriality, mechanical failure, weather pressure, dance phrasing, ritual, crowd behavior, etc.;
- do not copy the surface appearance of the analogy; transfer function, rhythm, force, hierarchy, or conflict.

### Phase C: EXPLORE
Only now assess the candidates for emotional clarity, usefulness, ZORR fit, and production feasibility.

## Diversity Gate R01
A proposal is rejected before drawing if any of these are true:
- weighted distance from any recent concept < 0.58;
- fewer than 7 of 12 surface dimensions changed;
- camera/pose/hand/light/palette signature overlaps too strongly with recent work;
- a motif appears 2+ times in the recent 4-concept window;
- emotion is carried by fewer than 4 independent channels;
- the supposed 'far analogy' is another anime/manga/style reference.

Emotion channels:
- face
- body
- hands
- space
- light/value
- environment
- temporal rhythm

Minimum active channels: 4. Strong ZORR emotion target: 5-7.

## Pattern cooldown
Until the debt is repaid, these are not defaults:
- chest-up portrait
- near-frontal slight-low camera
- squared static shoulders
- hand at lapel/chest
- brow-compression + stare as main emotion mechanism
- abstract black void
- colored rim/split light as automatic drama
- black/cream + one neon accent as automatic palette
- hatching as automatic intensity device
- posed emotional peak with no before/after state

Any of these can return only when the concept earns it functionally and the diversity gate still passes.

## Emotion must become behavior
Do not ask 'what face does jealousy have?'
Ask:
- What is the character trying to hide?
- What action is being interrupted?
- What does the body want to do while social control forbids it?
- Which hand betrays the internal state?
- Does the body advance, retreat, sink, widen, condense, freeze, oscillate?
- What happened 0.5 s before this frame and what will happen 0.5 s after it?

The answer determines the image. The eyebrow is only one local consequence.

## Production law
No image generation or illustration pass until the concept skeleton passes diversity gate. Short commands such as 'develop', 'continue', 'study', or 'work' do not authorize image generation.

## PASS definition
The thinking system passes only when adjacent concepts can be recognized as different visual strategies even after character identity, costume, color, and rendering style are removed.
