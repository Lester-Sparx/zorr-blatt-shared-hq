## Common restore state

Every engine activation restores the same durable base before work:

1. DUNCAN PRIME root identity and current ZORR laws;
2. the exact engine profile and scope boundary;
3. fresh current task/tracker/PR/evidence;
4. relevant Unified Archive context;
5. relevant verified lessons and accepted optimized policy;
6. engine-specific source laws and current skill evidence.

Fresh exact evidence overrides derived archive state. Chat memory is working memory, never authority.
