## Durable authority from #199

Global texture law:

`TEXTURE != NOISE`

Every material:

`BASE FIELD + MACRO FORM + STRUCTURAL EDGES + LIMITED MESO VARIATION + SPARSE MICRO ACCENTS + LIGHT`

Frequency law:

`MACRO > MESO > MICRO`

Default ordinary production surface envelope at intended screen scale:

- calm area usually `>=85%`
- structural/detail edge coverage usually `<=10%`
- main material palette roughly `4–6` value/color bands
- coarse-to-fine energy `E16/E1 >=2` preferred for calm materials
- fine residual p90 in calm zones `<=2% luminance` preferred
- random uniform grain = FAIL
- photo texture pasted over simplified geometry = FAIL
- structure-unrelated cracks/scratches/grain = FAIL
- distance-invariant microdetail = FAIL

Distance law:

- NEAR = macro + meso + sparse selected micro
- MID = macro + meso; micro collapses
- FAR = silhouette + large value/color masses

Important boundary: material-specific identity may locally exceed the ordinary envelope, but may not become uncontrolled high-frequency noise.

## EXISTING T05 IMPLEMENTATION AUDIT

The recovered existing ZORR T05 code uses OpenCV primitives:

1. Gaussian blur of the source at sigma `1.2`;
2. high-frequency residual `source - blur`;
3. Sobel gradient magnitude;
4. inverse edge weighting so restored residual is reduced near strong structural edges;
5. amplitude variants `A=1.20`, `B=0.45`, `C=0.00`;
6. high-frequency energy measured as mean absolute `gray - GaussianBlur(gray, sigma=1.2)`.

This is useful and already-proven existing ZORR code for one bounded question:

`HOW MUCH SOURCE HIGH-FREQUENCY AMPLITUDE MAY REMAIN?`

It is NOT sufficient to answer:

`WHICH HIGH-FREQUENCY INFORMATION BELONGS TO SKIN VS HAIR VS CLOTH VS LEATHER VS METAL?`

Root cause: the residual itself is source-frequency based, not material-semantic. Inverse edge weighting protects primary edges but does not classify residual marks by material meaning.

Therefore:

`T05-B = DENSITY CONTROL / NOT MATERIAL-TEXTURE LAW`

No modification is made to this code because new/custom code is forbidden by OWNER.

## SCALE + MATERIAL MODEL — REFINED

The evidence now supports two independent controls that must not be collapsed:

`TEXTURE = SCALE_BUDGET x MATERIAL_RESPONSE`

### SCALE_BUDGET

- HEAD / CLOSE = T05-B-like moderate structural micro-information is a provisional midpoint;
- MID = remove most micro information; keep material-defining meso structure;
- FULL BODY / FAR = cleaner than T05-B; primarily macro form, structural edges and only identity-critical accents.

### MATERIAL_RESPONSE

Within the scale budget, each material spends detail differently:

- skin spends detail on planes/scars/selected creases, not generic grain;
- hair spends detail on directional clusters, not equal-detail strands;
- ivory cloth spends detail on construction seams/tension folds;
- black cloth spends detail on silhouette/overlap and a few folds;
- leather spends detail on broad purposeful specular shapes;
- gold/silver spend detail as small focal/high-contrast islands;
- organic special surfaces may exceed ordinary density only when repeated marks follow anatomy/flow.

This separation resolves the false choice between `flat` and `detailed`: a surface may be materially specific while still obeying a lower scale budget.

## Cross-material laws extracted from TEX-TEACHER-01

1. `DETAIL != EVERYWHERE`.
2. High-frequency detail is profitable only when surrounded by calmer areas.
3. Material identity should come from different combinations of macro form, edge structure and specular logic rather than from one universal grain overlay.
4. Black materials should usually remain large readable masses; internal detail is subordinate.
5. Metal must read as form/panel/edge/specular before damage.
6. Leather must read as deep field + broad specular shape before any small surface cue.
7. Organic texture must follow anatomy/flow/volume rather than operate as random decoration.
8. Exact gothic motifs/design DNA from TEX-TEACHER-01 are not transferable ZORR laws.
