# ZORR — NO TEXT ON IMAGE LAW R01

STATUS = HARD OWNER OVERRIDE / DURABLE PRODUCTION RULE
DATE = 2026-08-31
SCOPE = all ZORR generated images, edited images, posters, key visuals, key drawings, promo stills

## HARD LAW

```text
TEXT / TYPOGRAPHY / CAPTIONS / LABELS / WATERMARK-LIKE MARKS = TABOO BY DEFAULT
```

Forbidden unless OWNER explicitly authorizes text for that specific image:
- titles;
- subtitles;
- poster captions;
- explanatory labels;
- decorative English/Japanese/Cyrillic lettering;
- pseudo-Japanese / generated gibberish glyphs;
- magazine copy;
- pseudo-logos;
- issue numbers;
- UI-like text;
- watermarks / signatures added by the image process.

## REFERENCE STUDY VS OUTPUT

Typography present in external references may still be studied or measured as composition evidence.

It does **not** authorize typography in ZORR output.

```text
REFERENCE HAS TEXT
!=
ZORR OUTPUT MAY HAVE TEXT
```

## SOURCE EDITS

If an existing source image already contains lettering, preserve or remove that source lettering only according to the explicit edit task. Do not invent additional lettering.

## VARIATION MATH OVERRIDE

`TYPOGRAPHY` may remain a measurement axis for external-reference/archive analysis, but it is not an active novelty axis for ZORR image generation/editing unless OWNER explicitly unlocks it.

Do not use text as a cheap way to make two images look more different.

## OVERRIDE OF EARLIER NOTES

This law supersedes any earlier ZORR note suggesting `TITLE = SHAPE`, typography as an active poster tool, decorative bottom labels, or text blocks as a default method of composition.

For ZORR output, use instead:
- non-text graphic masses;
- negative space;
- color fields;
- collage shapes without lettering;
- props / silhouettes / print texture;
- geometric blocks;
- controlled image-space asymmetry.

## TERMINAL LAW

```text
NO LETTERING ON THE IMAGE UNLESS OWNER EXPLICITLY ASKS FOR LETTERING.
```
