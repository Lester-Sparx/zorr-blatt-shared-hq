## 0. CENTRAL STYLE STATEMENT

ZORR visual language is not one recurring look. It is a controlled family of radically different presentations built around stable character identity and a repeatable quality of thinking.

Working synthesis:

```text
ADULT ANIME / MANGA ANATOMY
+ FASHION SILHOUETTE INTELLIGENCE
+ GRAPHIC BLACK-MASS CONTROL
+ EDITORIAL CROPPING
+ EXPRESSION AS GEOMETRY + ACTING
+ PRINT / COLLAGE MATERIALITY
+ OBJECT / ACCESSORY ACTING
+ CONTROLLED COLOR VIOLATION
+ PSYCHOLOGICAL NEGATIVE SPACE
+ BEHAVIORAL SURREALISM
+ IDENTITY PRESERVATION UNDER RADICAL PRESENTATION CHANGE
```

Terminal verbal law:

```text
STRANGE IDEA. CLEAN EXECUTION.
```

The style must be recognizable by its design intelligence, not by repeating one camera, one hand gesture, one lighting recipe, one suit, or one background.

## 1. REFERENCE-DERIVED CORE OBSERVATIONS

### 1.1 INFORMATION REMOVAL IS A DESIGN TOOL

Strong references repeatedly remove information rather than add it:
- face partly hidden by hair, shadow, hat, glasses, helmet, blade, hand or crop;
- limbs intentionally leave frame;
- the background collapses into a flat field or black void;
- large costume regions become pure black/white masses;
- details disappear in favor of one readable shape system.

Law:

```text
MORE INFORMATION != STRONGER IMAGE
SELECTIVE INFORMATION = STRONGER IMAGE WHEN THE REMAINING ANCHORS ARE AUTHORED
```

This directly opposes generic over-rendering.

### 1.2 IDENTITY IS DISTRIBUTED, NOT FACE-ONLY

Observed identity carriers include:
- skull/face geometry;
- hair silhouette;
- scar/face marks;
- earrings and jewelry;
- hat/helmet/glasses;
- shoulder width and torso proportion;
- coat/jacket silhouette;
- trouser volume;
- footwear;
- weapon/object/companion association;
- characteristic black/white mass arrangement.

Design test:

```text
IF FACE IS PARTLY HIDDEN,
CAN THE CHARACTER STILL BE READ FROM SILHOUETTE + COSTUME + ACCESSORY ANCHORS?
```

If not, the design is too face-dependent.

### 1.3 ALIVE ACTING IS EVENT-DRIVEN

The strongest references feel alive because the character is inside an event or state:
- shock/freeze;
- fatigue/sweat;
- listening;
- restrained threat;
- seated weight;
- weapon readiness;
- reach/contact;
- withheld reaction;
- predatory amusement;
- post-action exhaustion.

Production order:

```text
EVENT
-> INTENTION
-> BODY STATE
-> FORCE / WEIGHT
-> POSE
-> FACE
-> CLOTH / ACCESSORY RESPONSE
```

Do not begin with a generic pose and add an emotion afterward.

### 1.4 THE ACTION CARRIER MAY NOT BE THE HAND

A shot may be driven by:

```text
TORSO
HEAD
GAZE
HAND
WEAPON
CLOTHING
SHADOW
OBJECT
SECOND CHARACTER
CROP
NEGATIVE SPACE
TYPOGRAPHY
```

This is a direct anti-fixation rule. The hand is only one possible acting channel.

## 2. SILHOUETTE LANGUAGE

Silhouette is the first presentation layer after identity.

Observed useful silhouette systems:
- tall narrow vertical;
- broad seated triangle;
- compressed crouch;
- diagonal action wedge;
- head-dominant close-up;
- accessory-dominant profile;
- half-body black occlusion;
- oversized garment mass;
- weapon-as-horizontal-axis;
- body partially destroyed by crop.

### 2.1 BLACK-SILHOUETTE TEST

```text
REMOVE:
face detail
color
light FX
hatching
background texture

KEEP:
body contour
major costume masses
props
negative spaces

QUESTION:
Does the action / attitude / design family still read?
```

If no, the image is depending on polish rather than design.

### 2.2 SILHOUETTE MUST NOT BE THE SAME AS POSE PRESENTATION

A new crop is not automatically a new silhouette family. A new silhouette may come from:
- torso orientation;
- limb extension/compression;
- garment volume;
- object intersection;
- occlusion;
- negative-space change;
- seated/standing/leaning/crouched state.

This is compatible with #233 separation of POSE_ARTICULATION and POSE_PRESENTATION.

## 3. EMOTION / FACE LANGUAGE

### 3.1 FACE IS A SET OF PLANES AND LOCAL TENSIONS

Observed effective channels:
- eye aperture;
- visible sclera;
- pupil placement;
- upper-lid weight;
- lower-lid tension;
- brow-eye gap;
- asymmetric brow slant;
- nose as a major wedge/plane break;
- jaw compression/shift;
- mouth width/opening;
- mouth-corner asymmetry;
- cheek/nostril tension;
- shadow mask across the eye region;
- facial mark as graphic anchor.

Forbidden default:

```text
FURROWED BROWS + HARD STARE = EMOTION
```

### 3.2 STILLNESS CAN BE ALIVE

Strong still portraits use:
- micro head angle;
- non-mirrored eyelids;
- gaze off-camera;
- unequal facial planes;
- neck/jaw tension;
- controlled mouth state;
- partial occlusion.

Law:

```text
STILLNESS != SYMMETRY
```

### 3.3 EXPRESSION GEOMETRY != EMOTION TRUTH

Use #233:
- machine/math may measure visible geometry;
- acting intent remains authored;
- similar geometry may serve different narrative contexts.

## 4. HAND / BODY / PROP LANGUAGE

### 4.1 HAND AS GRAPHIC SHAPE

A hand can simultaneously perform:
- acting;
- silhouette shaping;
- depth;
- framing;
- negative-space creation;
- accessory display.

But it must still be mechanically owned by the body.

### 4.2 GLUED-HAND FAILURE

Use `ZORR_ANTI_DOLL_IDENTITY_ACTION_CHAIN_R01` as hard authority:

```text
INTENT
-> EYES / TARGET
-> SPINE / TORSO
-> SCAPULA / SHOULDER
-> UPPER ARM
-> ELBOW
-> FOREARM
-> WRIST
-> PALM
-> FINGER HIERARCHY
```

A large hand is not proof of action.

### 4.3 PROP AS COMPOSITIONAL AXIS

Strong references show objects acting as dominant geometry:
- blade across face;
- hat brim cutting eye line;
- chain crossing body;
- cigarette/can/object creating interaction;
- glasses turning eyes into graphic symbols.

Law:

```text
PROP != OBJECT HELD BY CHARACTER
PROP = POSSIBLE PRIMARY COMPOSITIONAL VECTOR
```

## 5. CROP / CAMERA LANGUAGE

Observed valid modes:
- full-body fashion silhouette;
- wide kinetic action;
- medium gesture state;
- tight psychological portrait;
- extreme close-up;
- asymmetric crop destroying half the body;
- profile/3-4 view;
- low/high camera only when it changes the design job.

Crop functions:
- magnify emotion;
- hide information;
- create motion beyond frame;
- change negative space;
- shift fashion emphasis;
- make an object dominate;
- remove the temptation to pose for a model sheet.

Law:

```text
NEW CROP != NEW POSE
```

## 6. BLACK / WHITE / VALUE MASS

References repeatedly rely on a few large value territories.

Preferred design thought:

```text
BIG DARK MASS
+ BIG LIGHT MASS
+ ONE ACTIVE MID / ACCENT SYSTEM
```

Avoid uniform detail density.

Thumbnail test:

```text
REDUCE IMAGE TO 5-10% SIZE
IF THE PRIMARY MASSES AND FOCAL PATH STILL READ -> MASS DESIGN SURVIVES
IF IT COLLAPSES INTO GREY NOISE -> DETAIL IS DOING TOO MUCH WORK
```

## 7. HATCHING / LINE LANGUAGE

Hatching is not decorative grit.

Possible jobs:
- form;
- tension;
- material;
- direction;
- psychological pressure;
- print materiality.

Use #233 independent channels:

```text
HATCH_DIRECTION
HATCH_DENSITY
HATCH_SPACING
STROKE_WIDTH
CROSSHATCH_STRUCTURE
```

Design rule:
- do not apply identical hatch direction/density to face, suit, background and FX;
- line hierarchy must distinguish silhouette, construction, expression and tone;
- sharp anime corners must not be over-smoothed by a generic correction process.

## 8. COLOR LANGUAGE

### 8.1 COLOR MAY BE PSYCHOLOGICAL, NOT PHYSICAL

Observed systems include:
- hot skin vs cold background;
- red total-look fashion;
- duotone/tritone faces;
- acid green on black;
- magenta/white/black face construction;
- cream/red/black print palettes;
- blue/white/black graphic simplification.

Law:

```text
COLOR ROLE
MAY BE
PHYSICAL LIGHT
OR
PSYCHOLOGICAL FIELD
OR
GRAPHIC HIERARCHY
OR
FASHION IDENTITY
```

Do not pretend one role is another.

### 8.2 COLOR PROPORTION IS A SEPARATE VARIABLE

Same swatches with different area ratios are different designs.

Use #233:
- palette role color;
- palette area mass;
- value/light treated separately from hue.

## 9. FASHION LANGUAGE

Fashion is body architecture, not decoration.

Observe and design:
- shoulder geometry;
- collar/lapel scale;
- waist suppression/expansion;
- coat length;
- trouser volume;
- shoe silhouette;
- sleeve compression;
- material stiffness;
- jewelry placement;
- glove/hat/glasses systems;
- total-look color mass.

Law:

```text
FASHION DESIGN MUST SURVIVE MOTION AND PARTIAL FACE LOSS
```

A beautiful costume that cannot be decomposed into plausible moving masses is a production defect.

## 10. ACCESSORY / MATERIAL ACTING

Accessories can become semantic actors:
- ring placement changes hand rhythm;
- chains create secondary flow lines;
- watches create status focal points;
- glasses alter eye geometry;
- earrings create secondary motion;
- weapon creates compositional force;
- footwear changes full-body silhouette.

Do not add accessories merely to increase detail count.

## 11. NEGATIVE SPACE

Negative space is authored geometry.

Possible jobs:
- isolation;
- claustrophobia;
- anticipation;
- typography reservation;
- directional pull;
- scale contrast;
- pressure around face/body;
- separation of multiple actors.

Design both positive and negative mass simultaneously.

## 12. TYPOGRAPHY / POSTER LAYOUT

Typography can function as:
- background architecture;
- dominant color block;
- pressure against silhouette;
- scale cue;
- directional vector;
- crop device;
- editorial/fashion signal.

Law:

```text
TITLE != LABEL
TITLE = SHAPE
```

Use #233 1080x1920 = 9x16 cells of 120x120 px for layout comparison.

## 13. PRINT / COLLAGE MATERIALITY

Observed print-language tools:
- halftone;
- rough ink;
- paper grain;
- faded color;
- offset-like misregistration;
- damaged poster texture;
- collage fragments;
- stamps / labels / documents;
- sparse editorial fields.

Important:

```text
PRINT MATERIALITY SHOULD FEEL LIKE A SHARED IMAGE MEDIUM,
NOT A FILTER APPLIED ONLY TO THE CHARACTER OR ONLY TO THE BACKGROUND.
```

## 14. PSYCHEDELIC LANGUAGE

Psychedelia is strongest when it violates one rule cleanly rather than filling the image with random psychedelic motifs.

Working law:

```text
NORMAL VISUAL LANGUAGE
+ ONE CONTROLLED IMPOSSIBLE RULE
= PSYCHEDELIC EVENT
```

Possible violations:
- object behaves incorrectly;
- shadow becomes independent;
- garment becomes spatial field;
- object scale breaks;
- perspective relation contradicts itself;
- face/background use incompatible graphic systems;
- repeated symbol invades reality;
- environmental continuity fails at one authored location.

Protect identity anchors.

## 15. APPROVED PRESENTATION FAMILIES TO EXPLORE

These are variation families, not mandatory presets.

### M01 — KINETIC ACTION
- strong diagonals;
- cropped limbs;
- overlap;
- clear force chain;
- action leaves frame.

### M02 — CONTROLLED STILLNESS
- little gross motion;
- micro asymmetry;
- eye/jaw/neck acting;
- quiet large shapes.

### M03 — EXTREME CLOSE-UP
- face dominates;
- aggressive crop;
- one emotional zone;
- background nearly removed.

### M04 — FASHION FULL-BODY
- silhouette first;
- costume architecture;
- face may be secondary/partly hidden;
- stance/weight communicates status.

### M05 — GRAPHIC DUOTONE/TRITONE
- 2-3 dominant colors;
- large black/white/colored masses;
- simplification stronger than texture.

### M06 — ACCESSORY / PROP DOMINANT
- object or jewelry participates in acting;
- object may set main compositional axis.

### M07 — COLLAGE / PRINT
- typography/labels/paper/raster become scene language;
- figure may be partially absorbed into print field.

### M08 — PSYCHEDELIC EVENT
- reality baseline remains readable;
- one impossible rule is introduced;
- identity remains anchored.

### M09 — OCCLUSION PORTRAIT
- partial face loss;
- shadow/hair/hat/object blocks information;
- remaining identity anchors become stronger.

### M10 — MULTI-ACTOR PRESSURE
- second character/object becomes psychological counter-shape;
- emotion emerges from relation, not isolated face.

## 16. FORBIDDEN DEFAULT PRESET

If the proposed shot defaults to most of the following, reject concept before polish unless narrative requires it:

```text
WHITE / CREAM SUIT
+ CHEST-UP / WAIST-UP
+ FRONT OR 3/4
+ FURROWED BROWS
+ HARD STARE
+ HAND NEAR CHEST / LAPEL
OR LARGE HAND TOWARD CAMERA
+ DARK MARBLE / CORRIDOR
+ VERTICAL RED/GREEN LIGHT STRIPE
+ SAME THREATENING ENERGY
```

The problem is not any single element. The problem is automatic recombination of the same system.

```text
8. PROP / ACCESSORY ROLE = ? (or NONE)
9. FACE EMOTION MECHANISM = ?
10. COLOR ROLE = physical / psychological / graphic / fashion
11. PRINT / TEXTURE ROLE = ?
12. PSYCHEDELIC RULE VIOLATION = ? (or NONE)
13. WHICH PRESENTATION FAMILY M01-M10 IS THIS CLOSEST TO?

```

If the concept cannot answer these, it is not ready for rendering.

## 19. REVIEW ORDER

For a finished or edited design, review in this order:

```text
1. IDENTITY / CANON PRESERVED?
2. ACTION OR STATE READS WITHOUT FX?
3. SILHOUETTE READS AT THUMBNAIL?
4. WEIGHT / FORCE / BODY CHAIN COHERENT?
5. HAND / PROP HAS A FUNCTION?
6. FACE ACTING USES MORE THAN BROWS?
7. FASHION RESPONDS TO BODY AND HAS ITS OWN SILHOUETTE?
8. NEGATIVE SPACE HAS A JOB?
9. VALUE MASS READS BEFORE DETAIL?
10. HATCH / LINE HAS A DECLARED FUNCTION?
11. COLOR ROLE IS CLEAR?
12. TYPOGRAPHY / COLLAGE / FX SUPPORT RATHER THAN MASK?
13. PSYCHEDELIC EVENT PRESERVES ANCHORS?
14. VARIATION PROFILE IS ACTUALLY DIFFERENT FROM RECENT WORK?
```

If item 1 fails, stop aesthetic review. If items 2-5 fail, do not rescue with light/FX/detail.

## 20. CURRENT DESIGN-ENGINE MANDATE

The design engine is not asked to produce 'another cool poster'.

Its job is:

```text
PRESERVE CHARACTER TRUTH
+ CHOOSE A DISTINCT PRESENTATION SYSTEM
+ ASSIGN A SPECIFIC ACTION / STATE
+ BUILD SILHOUETTE / MASS / NEGATIVE SPACE
+ USE FASHION / OBJECTS / COLOR / PRINT AS ACTING CHANNELS
+ INTRODUCE CONTROLLED STRANGENESS ONLY WHEN IT HAS A CAUSAL JOB
+ CHECK REPETITION AXIS-BY-AXIS
```

Terminal law:

```text
ZORR STYLE IS NOT A PRESET.
ZORR STYLE IS A DISCIPLINE OF IDENTITY + VARIATION + PSYCHOLOGICAL GRAPHIC FORCE.
```
