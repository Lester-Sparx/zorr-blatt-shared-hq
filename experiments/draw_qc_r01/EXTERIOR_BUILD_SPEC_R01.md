## Translation objective

Do NOT copy the photograph literally.

Translate its spatial and material logic into ZORR visual language:

`BIG GROUND MASS -> PERSPECTIVE FLOW -> DIRECTIONAL SURFACE RHYTHM -> DARK TREE SILHOUETTE -> ATMOSPHERIC COLLAPSE -> SPARSE DETAIL -> STOP`

The target is an original ZORR exterior using the source as an environment teacher, not a photoreal recreation.

## Global composition

### FACT / SOURCE-DERIVED

- Ground is the dominant area.
- Horizon is above the vertical center of the image.
- The strongest dark anchor is offset left.
- Large empty space is a major part of the composition.
- The track/erosion path provides directional depth.

### PROVISIONAL BUILD RANGE

Use normalized frame coordinates only as a composition guide, not as camera/lens truth:

- horizon target: approximately `0.34–0.43 H` from the top;
- tree-group visual center: approximately `0.17–0.28 W` from the left;
- tree base: approximately near the horizon band, not in foreground;
- primary open negative-space field: center-right and upper-right;
- ground should occupy roughly `57–66%` of the frame.

These ratios are composition transfer ranges, not canon geometry.

## GROUND

### Required macro structure

- one broad open sandy plane;
- low relief only;
- no large foreground props unless a later scene-specific requirement explicitly adds them;
- perspective must remain readable without clutter.

### Texture construction

Use:

`BASE FIELD + LARGE TERRAIN GRADIENT + 2–4 RIPPLE FAMILIES + TRACK/EROSION FLOW + SPARSE DEBRIS`

Do NOT use:

- uniform sand grain;
- random dots across the whole field;
- photographic noise;
- identical ripple frequency from foreground to horizon;
- cracks/details unrelated to wind/erosion structure.

### Scale law

NEAR:
- broader and clearer ripple groups;
- selected small debris/marks allowed;
- local edge contrast highest on ground.

MID:
- ripple spacing visually compresses;
- microdetail collapses;
- track/erosion path remains readable.

FAR:
- sand becomes a calm value/color mass;
- only large directional flow survives;
- no visible random grain.

## TRACK / FLOW LINE

The left-side track/erosion line is a structural depth device, not decoration.

Required functions:
- lead the eye from foreground toward the horizon/tree zone;
- reinforce perspective;
- imply prior movement/wind/erosion without becoming a road unless scene narrative later requires one.

FAIL if:
- it becomes a centered road;
- it becomes too dark and competes with the tree/character;
- it terminates randomly without supporting depth;
- it receives high-frequency detail all the way to the horizon.

## TREE GROUP

### Required role

`PRIMARY ENVIRONMENT SILHOUETTE ANCHOR`

Build order:

`TRUNK MASS -> MAJOR BRANCH FORKS -> SECONDARY BRANCH RHYTHM -> VERY LIMITED INNER DETAIL -> STOP`

Required:
- asymmetrical branching;
- dark silhouette against pale atmosphere;
- readable mass before bark/branch detail;
- tree remains visually simpler than a foreground character.

Forbidden by default:
- botanical microdetail;
- bark texture everywhere;
- dense leaf clusters inconsistent with the source;
- branch noise that destroys the silhouette;
- centering the tree as a postcard composition.

## SKY

Required structure:

`PALE COOL/NEUTRAL FIELD + LARGE CLOUD/MIST MASSES + SOFT HORIZON TRANSITION`

Source supports soft atmospheric light, not a hard directional sun.

Do NOT infer an exact sun azimuth, focal length, exposure, or cloud altitude from this single reference.

Forbidden:
- detailed cloud curls everywhere;
- high-saturation blue sky;
- dramatic hard sun rays unless a later explicit scene requirement supersedes the source;
- sky texture competing with silhouette readability.

## FOG / DUST

Purpose:

`DEPTH CONTROL, NOT DECORATIVE FX`

Required effects with distance:
- lower contrast;
- lower saturation;
- lower edge sharpness;
- lower texture density;
- partial merging of far ground and sky.

Dust/haze should read as environmental atmosphere.

Forbidden:
- opaque smoke walls;
- repeated particle dots everywhere;
- VFX streaks unrelated to wind direction;
- fog that erases the tree silhouette completely.

## WIND LANGUAGE

Wind is implied primarily through its effects on matter.

Priority:

`SAND RIPPLE DIRECTION -> DUST DRIFT -> TREE SHAPE/TENSION -> OPTIONAL SPARSE MOVING DEBRIS`

Do not rely on decorative anime wind-lines as the base solution.

One dominant wind direction should organize the environment. Exact physical wind speed/direction is NOT PROVEN from the still reference.

## DEPTH STACK

### FOREGROUND

- strongest ground texture;
- highest local edge clarity in the environment;
- largest ripple spacing;
- track/erosion line enters here.

### MIDGROUND

- reduced microdetail;
- tree group sits in or near this depth band;
- ripple groups become smaller/closer;
- atmospheric reduction begins.

### FAR / HORIZON

- very low texture density;
- low contrast;
- simplified ground/sky separation;
- no fine debris or sand grain.

Hard rule from #199 relationship:

`DISTANCE-INVARIANT MICRODETAIL = FAIL`

If DUNCAN is later explicitly ordered into this exterior:

`CHARACTER = PRIMARY READ`

`TREE = SECONDARY ENVIRONMENT ANCHOR`

`TRACK = DEPTH GUIDE`

## DETAIL BUDGET

Environment must stay below character focal density.

Order of information:

1. ground silhouette/plane and horizon;
2. tree silhouette;
3. track/depth flow;
4. broad sky/haze masses;
5. ripple families;
6. limited material accents;
7. sparse microdetail only where scale supports it.

If microdetail is visible before the large composition reads, the build is wrong.

## BUILD ORDER

1. `FRAME / HORIZON / NEGATIVE SPACE`
2. `GROUND MACRO PLANE`
3. `TREE SILHOUETTE`
4. `TRACK / PERSPECTIVE FLOW`
5. `SKY VALUE MASSES`
6. `FOG-DUST DEPTH COLLAPSE`
7. `GROUND RIPPLE FAMILIES`
8. `SELECTIVE MESO DETAIL`
9. `SPARSE MICRO ACCENTS`
10. `CHARACTER INTEGRATION`, only when explicitly commanded
11. `QC`

No later layer may repair a failed earlier layer by adding detail.

## QC GATES

### G1 COMPOSITION
PASS requires:
- ground dominates without feeling empty by accident;
- horizon supports depth;
- tree is asymmetrical and off-center;
- negative space remains intentional;
- track creates readable depth flow.

### G2 SILHOUETTE
PASS requires:
- tree reads at thumbnail scale;
- environment has no unnecessary competing dark masses;
- later character silhouette can remain primary.

### G3 TEXTURE
PASS requires:
- `MACRO > MESO > MICRO`;
- ripple/detail density collapses with distance;
- no uniform photographic grain;
- foreground detail does not become random noise.

### G4 ATMOSPHERE / DEPTH
PASS requires:
- distance reduces contrast/edge/detail;
- far ground and sky integrate atmospherically;
- tree remains readable.

### G5 COLOR / VALUE
PASS requires:
- warm ground vs cooler pale atmosphere remains legible;
- saturation remains controlled;
- tree/character focal hierarchy is stronger than background texture.

### G6 CHARACTER INTEGRATION
Only applicable after explicit OWNER generation/build command involving a character.

PASS requires:
- correct ground contact;
- compatible scene light;
- no pasted model-sheet look;
- DUNCAN identity geometry preserved;
- environment remains subordinate.

## Immediate FAIL list

- photoreal sand pasted under graphic character;
- uniform grain/noise;
- every ripple equally sharp to the horizon;
- centered hero tree without compositional reason;
- dense bark/branch microdetail;
- dramatic hard lighting unsupported by the source;
- decorative dust/particles becoming the focal point;
- track turning into a high-contrast road by accident;
- background edges competing with character silhouette;
- adding objects merely to make the empty terrain look "busy";
- inventing exact lens/FOV/sun values from insufficient evidence.
